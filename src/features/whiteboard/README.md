# Chat whiteboard

`AgentConsole` keeps chat/live subscription and its composer mounted beneath a body-portal dialog. A captured runtime/epoch/session target owns each board; changing the chat identity unmounts that owner, aborts requests, closes SSE, and queues the last draft for local persistence. Explicit inertness and focus containment keep the background inactive while allowing Excalidraw’s own portalled dialogs and the shared chat image preview; Back restores focus. Sending dismisses only the send sheet. A temporarily missing live-chat snapshot pauses sending without dismissing the canvas; only a confirmed runtime/epoch/session replacement unmounts the old board.

- `boardApi.ts`: fixed shared Zod contracts, CAS saves, hint-only SSE, matching `invoked` ACK validation and timeouts. Preserves machine-readable `board_stale` for confirmed pre-write rejection; no automatic retry of uncertain mutations.
- `BoardController.ts`: serialized save loop and three-way rebasing against the actual acknowledged scene; newer edits survive pending reads/saves. Defers incoming scenes during native gestures. Only confirmed `board_stale` rejects allow up to three reconciliations per flush; uncertain writes remain paused across reload. Explicit recovery archives the local scene before replacement and checks for edits during fetch. Reads may reconnect.
- `draftStore.ts`: IndexedDB drafts scoped by pane/session, with stable board id, actual base scene/revision, paused state and one prior-recovery scene recorded in each draft. Legacy dirty drafts without a base stay paused. Writes are serialized/coalesced. Drawing and optional instruction survive offline/reload when storage is available; failures are visible. Back flushes server saves, or offers an explicit locally saved departure.
- `mergeScene.ts`: deterministic per-ID whole-record reconciliation: independent changes survive, local competing edits win, and new deletions win. Preserves native ordering/files/tombstones and rejects unsafe relation/asset/ID/size conflicts; strips restoration-only changes from untouched native records.
- `BoardEditor.tsx`: reports stroke/text/multipoint interaction boundaries, clears undo after applying a reconciled generation, and cancels deferred idle callbacks on unmount. Loaded only after `window.EXCALIDRAW_ASSET_PATH = '/excalidraw/'`. Native file data is preserved for referenced images, including deleted elements. Programmatic callbacks use a version fingerprint to avoid dirty-save loops. All nondeleted elements are exported, including off-screen elements, with fonts ready, a white background, no scene embedding, maximum dimension 2400, and a PNG strictly smaller than 10 MiB.
- `Whiteboard.tsx`: Share drawing opens an image-only preview sheet, with post-export/post-upload target and revision validation. Dock prompts flush the current native scene, capture its revision/fingerprint, export/upload a PNG for nonempty boards, then send the upload ID and board context through the parent mutation. Empty/deleted-only boards skip the image. Canvas interaction is locked while preparing; capability/target, editor validity, revision and fingerprint are checked again after export and upload. Export/upload failure never falls back to an image-less prompt; drafts remain and no automatic retry occurs. Editing authority is visible in the dock. Retained instruction on uncertain sends, live revoke status and snapshot links remain. The sheet freezes drawing and makes the dock inert. The dialog follows the visual viewport so mobile keyboards do not hide the composer.
- `ConversationDock.tsx`: uses `../agents/ChatTranscript.tsx`, exactly as main chat does, with the complete available bounded message array and the same thinking preference. Expansion changes geometry only, never filters messages. Snapshots live outside the transcript in a separate collapsible section (visible on wide landscape or expanded narrow layouts). Cached messages survive temporary unavailability but are destroyed with their captured board target. The composer is controlled by AgentConsole: it shares the ordinary chat text draft and sends through the existing mutation using boardApi.prompt with only the prepared board PNG, never hidden chat images. The board prompt endpoint issues a fresh edit grant after validating conversation ownership, the optional PNG upload, current revision, capability and idle state. Nonempty boards require an image. It forwards that PNG through the existing Pi image pipeline without creating immutable captures or consuming the Saved snapshots limit. The image-send endpoint only accepts image mode and never grants tools. Cmd/Ctrl+Enter sends; Enter and IME composition are left alone.

`ChatTranscript.tsx` owns shared message rendering, image preview/failure UI, truncation/empty states, and reader-follow behavior. It reuses `Console.module.css`, so there is no second whiteboard message theme. ResizeObserver and streaming updates retain the reader's scroll position unless following the bottom; programmatic/clamped scroll events never silently opt the reader into following. Image previews portal to body and isolate Escape/cancel so the surrounding whiteboard remains open.

`Whiteboard.module.css` gives the workspace a side-by-side layout at >=64rem in landscape (chat width clamped to 20–28rem, approximately 34%). Expand widens chat to 50%. Narrow/portrait layouts use the compact bottom panel; Expand hides, but does not unmount, the editor and fills the workspace with chat. `ConversationDock.module.css` sizes the shared viewport through its `data-ui` contract. The workspace is a size-query container so keyboard-visible visual-viewport reductions can relax panel limits without hiding the composer.

Agent activity lives in one row at the top of the chat panel: pending requests, current read/edit permission (with Stop access/Stop editing), ordinary agent work, or a reply present in the latest turn. Busy is not treated as disconnected. Actual connection/storage/operation failures use warning styling in that same row; a disconnected permission is labelled as last-known rather than silently revoked. The UI does not infer completion from the forwarding ACK or retain a separate forwarding banner. A board connection failure blocks both whiteboard prompts and drawing sharing until recovery; ordinary chat outside the mode remains independent.

AgentConsole revalidates the captured board owner, runtime/epoch/session, live connection, protocol version and busy/pending state before a text submission. A synchronous latch prevents duplicate taps before React renders pending state; failed sends retain the shared draft and are never replayed. Back/reopen preserves text and uncertain-send errors through the parent; confirmed identity replacement closes the old dock, and a late ACK cannot clear the replacement conversation's draft. Ordinary chat draft durability remains the existing in-memory behavior, not IndexedDB recovery.

## Integration / validation

The build supplies `/excalidraw/fonts`; the HTTP server owns CSP, board endpoints, and extension support. The pinned vendor CDN fallback is rewritten to same-origin by `tools/local-excalidraw-fonts.ts` for both dependency optimization and production builds. Missing board endpoints explain `/reload`; version-2 connections without the boards capability can still use image mode when the board endpoint is available. No separate model context or transcript rewriting is introduced.

Tests use mocked native editor, fetch, EventSource, and storage. Shared transcript tests cover complete messages, thinking, tool errors, image previews, empty/truncated states and follow/reader behavior across clamped resizes. Browser fixtures check transcript markup parity, landscape/portrait/rotation, compact/expanded views, image Escape handling and native drawing retention. Existing tests cover permission defaults, uncertain delivery, target invalidation/unmount, programmatic versus human changes, serialization, CAS conflicts, recovery, exports, revocation, and chat draft preservation. Run `npm run check` from the isolated worktree. Browser verification must also cover the real lazy-loaded editor and production CSP: mocks alone do not catch native optional fields or font fallback behavior.

## Deliberate limitations

- Share drawing always includes the full board; selection-only export is not implemented. The dock's Send action includes the full-board PNG for visual context plus request-scoped native-board editing access. This image reflects the sent revision, not subsequent edits; interpreting handwriting still requires a vision-capable model.
- Agent additions apply to the latest saved scene; updates/deletes and explicit dependsOn targets compare full native fingerprints captured by paginated board_read, even at the current revision. Changed targets skip their operations/groups and report reasons; independent eligible edits commit once. Browser scenes merge automatically for independent edits, with local competing edits/deletion priority. Native relation/asset/ID conflicts still use explicit recovery. Reconciled remote application clears undo rather than merging histories.
- Durability depends on available IndexedDB storage and completion of its transaction. Browser/process termination before a write completes cannot be guaranteed; quota/private-mode failures are surfaced, not claimed as saved.
- Native external links and embeddables are blocked/rejected; collaboration, help/library entry points, and the file-loading menu are hidden. Download remains local. The shared schema determines supported native element/file types.
- Chromium desktop/tablet/phone captures and production PNG previews were verified. Physical iPad/Apple Pencil testing remains outstanding; viewport emulation is not physical-device verification.
